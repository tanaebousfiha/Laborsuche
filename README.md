Laborsuche DACH – Interaktive Karte für Gesundheitsanbieter


Dieses Projekt ist eine interaktive Webkarte, die im DACH-Raum:
Anbieter für DEXA Body Composition Scans und Blutuntersuchungen als Selbstzahler visualisiert. Die Karte zeigt die Standorte, Details und Kontaktinformationen der Anbieter, um Nutzern bei der Suche nach passenden Gesundheitsdiensten zu helfen.
